国际贸易实务——FOB价格计算器和PISC生成器

默认分类 · 2026-11-24 · 6 分钟阅读
tech

在国际贸易中，业务员常常需要根据各种参数和变量来计算最终价格，费时费力，且常常需要更新形式发票和商业合同。本程序是一个面向出口贸易的单页报价计算工具，以 ROG Falchion Ace 75 HE 磁轴机械键盘为示例商品，帮助出口业务员把采购成本、海运费、保险和贸易条款换算成 FOB / CIF 单价与报价总额，并一键生成可直接打印的形式发票（Proforma Invoice，PI）与销售合同（Sales Contract，SC）。工具内置 11 种 Incoterms 2020、覆盖全球 9 大航区 60 余个目的港的整柜海运费数据库，以及增值税、出口退税、利润率、保险加成等完整成本模型，支持中英双语切换、浏览器本地保存与 A4 打印。界面采用「纸张 + 墨色 + 账本数字」的账房风格，左侧为条件输入与报价阶梯，右侧为实时更新的正式单据。

一、产品定位与用途

这个计算器要解决的是外贸报价中最繁琐、也最易出错的一环：把一件商品从工厂成本推到「装运港船上交货（FOB）」或「成本、保险加运费（CIF）」的最终卖价，并形成正式交易文件。

传统做法是业务员在 Excel 里手搭公式、逐港查运价、反复核对退税与保险，再把数字誊进 Word 单据——环节多、易漏、版本乱。这个工具把「算价」和「出单」合并成一条自动化流水线：

  • 谁来用：出口商、外贸业务员、跟单员、报价员。
  • 什么时候用：收到海外买家询盘后，从报价到签单的整个前置环节。
  • 怎么用：选定装货港、目的港、数量、颜色、运输方式、贸易条款和付款方式，即可同时得到单价、总额，并立即得到一份可供买家签回的 PI 或 SC。
  • 改一个数字，左侧总价和右侧单据同步刷新，避免「表格算一套、单据写一套」的不一致；同时把易出错的海运费、退税额、保险加成全部封装进可追溯的公式里。

二、主要功能

  • 报价计算：输出 FOB 单价、CIF 单价、保险费、报价总额 四项核心数字并实时联动；附带「单价拆解」账本，逐项展示含税采购、退税抵扣、本地费用、包装认证、利润，让客户可见的卖价与内部成本逻辑一一对应。
  • 贸易条款：完整支持 EXW、FCA、CPT、CIP、DAP、DPU、DDP、FAS、FOB、CFR、CIF 共 11 种 Incoterms 2020。程序按术语的「计费基础」自动判断运费、保险费是否计入单价：EXW 只含货值，FCA/FAS/FOB 按 FOB 口径，CPT/CFR 加运费，CIP/CIF 再加保险，DAP/DPU/DDP 加运费但提示未含目的地费用。
  • 运输方式与运费自动换算：内置深圳/香港出发至全球各港的 40HQ 整柜运费表，默认按「整柜运费 ÷ 每柜装载量（3000 件）」自动折算单件运费；并支持海运 / 铁路 / 空运三种模式——铁路默认按海运 ×1.8、空运按海运 ×6 作为初始值，可在后台逐港逐方式修改，且强制校验「海运 ≤ 铁路 ≤ 空运、非负」。
  • 样本单：数量低于 MOQ（50 件）时自动切换为样本单计价，采用预设的样本 FOB 基准单价（现为 280 USD/件），付款条款同步改为「出运前付清 100% / 开立 100% 即期信用证」，且数量固定、不适用 ±5% 溢短装。
  • 成本后台：集中管理含税采购价、增值税率、出口退税率、本地费用、包装认证、利润率、保险费率、投保加成，以及逐港的海运 / 铁路 / 空运费率。
  • 买卖双方、银行资料：卖家/买家的名称、地址、联络方式、PO 编号，以及受益人、开户行、SWIFT、账号，一次填写、两套单据复用。
  • 单据：PI 与 SC 两种文档一键切换，含货物描述、HS 编码、装箱资料、贸易/付款/保险/包装条款、金额大写，以及质量索赔、不可抗力、仲裁、违约与责任限制等法律条款；运输方式切换时，单证措辞自动从海运提单（B/L）换为铁路运单或空运提单（AWB）。
  • 打印：A4 竖版打印样式，只输出单据、自动隐藏左侧操作面板与选项卡，页眉墨线、表格斑马纹、分页断点均按正式单据排版。
  • 多语言：繁体中文 / 英文即时切换，单据遵循「英文在前 + 繁体在后」的双语排版惯例。

三、核心计算逻辑

以「单件成本」为轴，逐层推导：

代码块

出口退税抵扣   = 含税采购价 ÷ (1 + 增值税率) × 退税率
净采购成本     = 含税采购价 − 退税抵扣
单件总成本     = 净采购成本 + 本地费用 + 包装/认证
单件海运费     = 整柜运费 ÷ 每柜装载量（可逐港逐方式覆写）
EXW 单价       = (净采购成本 + 包装/认证) × (1 + 利润率)
FOB 单价       = 单件总成本 × (1 + 利润率)
CIF 单价       = (FOB 单价 + 运费) ÷ (1 − 投保加成 × 保险费率)
保险费         = CIF 单价 × 投保加成 × 保险费率
报价总额       = 对应条款单价 × 数量

程序再根据所选 Incoterm 的计费基础（exw / fob / freight / insured / delivery）决定最终采用的单价口径，并判断运费与保险费是否计入报价：

计费基础 采用口径 代表术语
exw EXW 单价 EXW
fob FOB 单价 FCA、FAS、FOB
freight FOB + 运费 CPT、CFR
insured CIF 单价（含保险） CIP、CIF
delivery FOB + 运费（另提示未含目的地费用） DAP、DPU、DDP

以默认值代入（采购价 118.57、增值税 13%、退税率 13%、本地费用 2.57、包装认证 0.71、利润率 15%、运费 1.20、保险费率 0.3%、投保加成 10%、数量 300 件）：

代码块

退税   = 118.57 ÷ 1.13 × 0.13 ≈ 13.64
净采购 = 118.57 − 13.64     ≈ 104.93
总成本 = 104.93 + 2.57 + 0.71 = 108.21
FOB    = 108.21 × 1.15      ≈ 124.44 USD/件
CIF    = (124.44 + 1.20) ÷ (1 − 1.1 × 0.003) ≈ 126.06 USD/件
总额   = 124.44 × 300       = 37,332.00 USD

四、界面结构

  • 顶栏：ROG 字标、产品标题与副标、语言切换（繁體/EN）、后台设置入口。
  • 左侧栏：
    • 01 裝運條件：装货港、数量、颜色（黑/白/红）、目的港、运输方式（海/铁/空）、运费读数、贸易条款、付款方式（T/T 或 L/C）。
    • 02 報價：报价总额（大号账本数字）+ FOB / CIF / 保险费阶梯，可展开「单价拆解」查看采购、退税、费用、利润明细，底部为设置入口。
  • 右侧单据栏：PI / SC 选项卡（吸顶）、打印按钮，以及实时渲染的正式单据。
  • 后台设置弹窗：成本与利润、运输费率、买卖双方、收款银行四组表单，Esc 关闭并回焦。

五、技术实现

  • 前端：单个 HTML 文件，HTML + CSS + 原生 JavaScript（ES6+），无框架、无外部依赖，双击即可离线使用。
  • 持久化：通过 localStorage 保存所有成本、双方资料、运费率、所选颜色/条款/运输方式，关闭浏览器后不丢失；并内置货币折算、样本单价 150→280、旧整柜运费模型等三组一次性迁移。
  • 国际化：集中式 I18N 文案表 + 运行时 applyI18n() 替换，术语、单据说明均有中英双语。
  • 金额大写：内置 numToWords() 算法，将美元金额转为英文正式大写（SAY TOTAL: US DOLLARS ... ONLY）。
  • 打印：@media print 单独定义 A4 版式，隐藏交互元素，控制分页断点。
  • 渲染：任何输入触发 update() → calc()（内部先 freightCalc() 取当前港口与运输方式的运费）→ 更新左侧账本与右侧单据的 innerHTML；单据中的缩写（L/C、T/T、B/L、C/O）经后处理包裹为不换行文本，避免窄栏拆行。
